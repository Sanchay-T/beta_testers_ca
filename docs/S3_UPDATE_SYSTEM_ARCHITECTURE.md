# CypherEdge S3 Update System - Comprehensive Documentation

## Overview

CypherEdge uses **DigitalOcean Spaces** (S3-compatible CDN) for delivering application updates via the **electron-updater** library. The system provides automatic background downloads with manual installation control, complete with database backups and graceful cleanup before updates.

#### Event Handlers (lines 298-1223)

```javascript
// 1. Checking for update
autoUpdater.on("checking-for-update", () => {
  log.info("Update check initiated");
  win?.webContents.send("update-status", "checking");
});

// 2. Update available
autoUpdater.on("update-available", (info) => {
  log.info(`Update available: ${info.version}`);

  // System requirements check (RAM >= 8GB)
  const requirements = systemInfo.getSystemRequirementsCheck();
  if (requirements.hasInsufficientRAM) {
    win?.webContents.send("update-status", "system-requirements-failed");
    return; // Block update download
  }

  // Notify frontend
  win?.webContents.send("update-status", "available", {
    version: info.version,
    releaseDate: info.releaseDate
  });
});

// 3. Update not available
autoUpdater.on("update-not-available", (info) => {
  log.info("App is up to date");
  win?.webContents.send("update-status", "not-available");
});

// 4. Download progress
autoUpdater.on("download-progress", (progress) => {
  // Log every 10% to avoid spam
  if (Math.floor(progress.percent) % 10 === 0) {
    log.info(`Download progress: ${Math.round(progress.percent)}%`);
  }

  // Send to frontend for progress bar
  win?.webContents.send("update-progress", {
    percent: progress.percent,
    transferred: progress.transferred,
    total: progress.total
  });

  // Show subtle progress in taskbar
  win?.setProgressBar(progress.percent / 100);
});

// 5. Update downloaded
autoUpdater.on("update-downloaded", async (info) => {
  log.info(`Update downloaded: ${info.version}`);

  // Set updating flag to skip confirmation dialogs
  isUpdating = true;
  sessionManager.logoutUser();

  // Create success flag for next startup
  const updateFlagPath = path.join(app.getPath("userData"), "update-success.txt");
  fs.writeFileSync(updateFlagPath, info.version);

  // Show installation progress window
  const installingWindow = new BrowserWindow({
    width: 350,
    height: 100,
    frame: false,
    alwaysOnTop: true,
    // ... minimal progress UI
  });

  // Run cleanup (stop Python backend, Gateway service)
  await cleanupForUpdate();

  // Install update after 3 seconds
  setTimeout(() => {
    autoUpdater.autoInstallOnAppQuit = false; // Install immediately
    autoUpdater.quitAndInstall(true, true); // Silent install, force restart
  }, 3000);

  // Notify frontend
  win?.webContents.send("update-downloaded", { version: info.version });
});

// 6. Error handling
autoUpdater.on("error", (error) => {
  log.error("Update error:", error);
  win?.webContents.send("update-error", error.message);
});
```

#### Cleanup Function (lines 663-850)

```javascript
async function cleanupForUpdate() {
  log.info("Admin-level cleanup sequence initiated");

  try {
    // 1. Stop Python backend process
    if (pythonProcess) {
      pythonProcess.kill("SIGTERM");
      log.info("Python backend stopped");
    }

    // 2. Stop Gateway service (Windows Service or process)
    if (process.platform === "win32") {
      execSync("sc stop LicensingServer", { stdio: "ignore" });
      log.info("Gateway service stopped");
    }

    // 3. Close all windows except installation progress
    BrowserWindow.getAllWindows().forEach((window) => {
      if (!window.isInstallationWindow) {
        window.close();
      }
    });

    // 4. Wait 3 seconds for cleanup to settle
    await new Promise(resolve => setTimeout(resolve, 3000));

    log.info("Cleanup completed successfully");
  } catch (error) {
    log.error("Cleanup error:", error);
  }
}
```

```javascript
contextBridge.exposeInMainWorld("electron", {
  // Update API
  updates: {
    checkForUpdates: () => ipcRenderer.invoke("check-for-updates"),
    // downloadUpdate: () => ipcRenderer.invoke("download-update"), // Not used
    // installUpdate: () => ipcRenderer.invoke("install-update"), // Not used

    // Event listeners
    onUpdateStatus: (callback) =>
      ipcRenderer.on("update-status", (_, status) => callback(status)),
    onUpdateProgress: (callback) =>
      ipcRenderer.on("update-progress", (_, progress) => callback(progress)),
    onUpdateDownloaded: (callback) =>
      ipcRenderer.on("update-downloaded", () => callback()),
    onUpdateError: (callback) =>
      ipcRenderer.on("update-error", (_, error) => callback(error)),

    removeUpdateListeners: () => {
      ipcRenderer.removeAllListeners("update-status");
      ipcRenderer.removeAllListeners("update-progress");
      ipcRenderer.removeAllListeners("update-downloaded");
      ipcRenderer.removeAllListeners("update-error");
    }
  },

  // System requirements API
  system: {
    getSystemRequirements: () => ipcRenderer.invoke("get-system-requirements"),
    overrideSystemRequirements: () => ipcRenderer.invoke("override-system-requirements")
  }
});
```

### 3. React UI Component

**File**: `frontend/react-app/src/components/UpdateNotification.js`

```javascript
const UpdateNotification = () => {
  const [updateStatus, setUpdateStatus] = useState("idle");
  const [progress, setProgress] = useState(0);
  const [isInstalling, setIsInstalling] = useState(false);
  const { updates } = window.electron;

  // Handle install update with full-screen modal
  const handleInstallUpdate = async () => {
    console.log('[UPDATE-UI] User clicked "Restart Now"');
    setIsInstalling(true);

    // Wait 3 seconds to show modal before quitting
    setTimeout(async () => {
      await updates.installUpdate();
    }, 3000);
  };

  useEffect(() => {
    // Set up update event listeners
    updates.onUpdateStatus((status, info) => {
      setUpdateStatus(status);

      if (status === "available") {
        toast({
          title: "Update Available",
          description: `A new version (${info?.version}) is available.`,
          action: (
            <button onClick={() => updates.downloadUpdate()}>
              Download
            </button>
          ),
          duration: 0
        });
      }
    });

    updates.onUpdateProgress((progressObj) => {
      setProgress(progressObj.percent || 0);
    });

    updates.onUpdateDownloaded((info) => {
      setUpdateStatus("ready");
      toast({
        title: "Update Ready",
        description: `Version ${info?.version} will be installed on restart`,
        action: (
          <button onClick={handleInstallUpdate}>
            Restart Now
          </button>
        ),
        duration: 0
      });
    });

    updates.onUpdateError((error) => {
      setUpdateStatus("error");
    });

    // Check for updates initially
    updates.checkForUpdates().catch(console.error);

    return () => updates.removeUpdateListeners();
  }, []);

  // Render UI based on status
  if (updateStatus === "downloading") {
    return (
      <div className="fixed bottom-4 right-4 bg-background">
        <h3>Downloading Update</h3>
        <div className="progress-bar">
          <div style={{ width: `${progress}%` }} />
        </div>
        <p>{progress.toFixed(1)}%</p>
      </div>
    );
  }

  // Full-screen installation modal
  if (isInstalling) {
    return (
      <div style={{ /* Full-screen overlay styles */ }}>
        <div>⚙️</div>
        <h2>Installing Update</h2>
        <p>CypherEdge is being updated to the latest version.</p>
        <p>The application will restart automatically.</p>
      </div>
    );
  }

  return null;
};
```

**Features**:
- Toast notifications for update availability
- Progress bar during download
- Full-screen modal during installation
- System requirements check (blocks update if RAM < 8GB)

### 2. Upload to Spaces Script

**File**: `upload.py`

**Purpose**: Uploads `.exe` and `latest.yml` to DigitalOcean Spaces using boto3 (S3-compatible client).

```python
import boto3
import os
from pathlib import Path
from dotenv import load_dotenv

# Load credentials from frontend/.env
load_dotenv('frontend/.env')

ACCESS_KEY = os.getenv('AWS_ACCESS_KEY_ID')
SECRET_KEY = os.getenv('AWS_SECRET_ACCESS_KEY')
REGION = 'blr1'
BUCKET = 'cypheredge-exe-uat'
ENDPOINT = f'https://{REGION}.digitaloceanspaces.com'
SPACES_PATH = "releases/windows"

# Find .exe and latest.yml in frontend/dist/
DIST_DIR = Path('frontend/dist')
exe_file = list(DIST_DIR.glob("*.exe"))[0]
latest_yml = DIST_DIR / 'latest.yml'

# Initialize S3 client (S3-compatible)
client = boto3.client(
    's3',
    region_name=REGION,
    endpoint_url=ENDPOINT,
    aws_access_key_id=ACCESS_KEY,
    aws_secret_access_key=SECRET_KEY
)

# Upload .exe
client.upload_file(
    str(exe_file),
    BUCKET,
    f"{SPACES_PATH}/{exe_file.name}",
    ExtraArgs={
        'ACL': 'public-read',
        'ContentType': 'application/x-msdownload'
    }
)

# Upload latest.yml (with no-cache headers)
client.upload_file(
    str(latest_yml),
    BUCKET,
    f"{SPACES_PATH}/latest.yml",
    ExtraArgs={
        'ACL': 'public-read',
        'ContentType': 'text/yaml',
        'CacheControl': 'max-age=0, no-cache, no-store, must-revalidate'
    }
)

print("✅ Deployment successful!")
print(f"Installer: https://cypheredge-exe-uat.blr1.cdn.digitaloceanspaces.com/releases/windows/{exe_file.name}")
print(f"Manifest:  https://cypheredge-exe-uat.blr1.cdn.digitaloceanspaces.com/releases/windows/latest.yml")
```

**Usage**: `npm run upload:spaces` (from frontend/)

**Dependencies**:
- Python 3.x
- `boto3` package (`pip install boto3`)
- `python-dotenv` package (`pip install python-dotenv`)

## Key Features

### 1. Automatic Background Downloads
- `autoDownload: true` enables silent downloads
- No user interaction required during download
- Minimal UI (subtle taskbar progress)

### 2. System Requirements Gating
- Checks RAM before downloading update
- Blocks updates on systems with < 8GB RAM
- Shows warning toast with system info

### 3. Database Backup
- Automatic database backup before update
- Saved to `%APPDATA%\CypherEdge-UAT\backups\`
- Timestamped filename: `db-backup-2025-11-12T14-30-00.sqlite`

### 4. Graceful Cleanup
- Stops Python backend process
- Stops .NET Gateway service
- Closes all app windows (preserves installation modal)
- 3-second settlement wait before install

### 5. Integrity Verification
- SHA512 hash validation by electron-updater
- Prevents corrupted update installation
- Early detection of ASAR corruption (integrity check on startup)

### 6. CDN Acceleration

### 7. Differential Updates Disabled

## Troubleshooting

### Issue: Updates Not Detected

**Symptoms**: App never shows "Update Available" notification

**Diagnosis**:
1. Check `latest.yml` is accessible:
   ```bash
   curl https://cypheredge-exe-uat.blr1.cdn.digitaloceanspaces.com/releases/windows/latest.yml
   ```
2. Verify version in `latest.yml` > current app version
3. Check electron logs: `%APPDATA%\CypherEdge-UAT\logs\main.log`
4. Look for "Update check initiated" and "Update available" messages

**Solution**:
- Ensure `latest.yml` has correct version and public-read ACL
- Check CDN propagation (can take 1-2 minutes)
- Verify `UPDATE_SERVER_URL` in `.env` matches CDN URL

### Issue: Download Fails

**Symptoms**: Download starts but fails midway, or error toast appears

**Diagnosis**:
1. Check logs for "Update download failed" errors
2. Verify installer file is accessible:
   ```bash
   curl -I https://cypheredge-exe-uat.blr1.cdn.digitaloceanspaces.com/releases/windows/CypherEdge-UAT-Setup-2.3.410.exe
   ```
3. Check SHA512 hash matches `latest.yml`

**Solution**:
- Re-upload installer to Spaces with correct ACL (`public-read`)
- Verify SHA512 hash in `latest.yml` is correct
- Check network connectivity and firewall rules

### Issue: Install Fails or App Doesn't Restart

**Symptoms**: App quits but doesn't restart with new version

**Diagnosis**:
1. Check NSIS installer logs: `%TEMP%\cyphersol-updates\`
2. Look for hung processes: Task Manager → "CypherEdge"
3. Check if old version is still running

**Solution**:
- Manually kill all CypherEdge processes
- Run uninstaller from Control Panel
- Download and install fresh from CDN
- Check `cleanupForUpdate()` function for missed processes

### Issue: System Requirements Block

**Symptoms**: Update downloads are blocked with "System Requirements Failed" toast

**Diagnosis**:
1. Check system RAM: `systemInfo.getMemoryGB()`
2. Look for "System requirements check" logs
3. Verify threshold (8GB minimum)

**Solution**:
- Upgrade system RAM to 8GB+
- Override temporarily (dev mode only): `window.electron.system.overrideSystemRequirements()`
- Adjust threshold in `SystemInformation.js` (not recommended for production)

### Issue: App-Update.yml Not Found in Packaged App

**Symptoms**: `app-update.yml` missing in `resources/` after build

**Diagnosis**:
1. Check if `publish` config exists in `package.json`
2. Verify electron-builder version (requires >= 24.13.3)

**Solution**:
- Ensure `publish` section in `package.json` is correct
- Rebuild app: `npm run build`
- Check `dist/win-unpacked/resources/app-update.yml` exists
